# MEDIA MACHINE - Sitio Web Corporativo

## 🚀 Descripción del Proyecto

Sitio web corporativo moderno, profesional y totalmente responsivo para MEDIA MACHINE.

Soluciones audiovisuales, pantallas LED, señalización digital y sistemas tecnológicos.

## 📋 Características

- ✨ Diseño moderno y corporativo
- 📱 Totalmente responsivo
- ⚡ Carga rápida
- 🎨 Efectos Glassmorphism
- 🔍 SEO optimizado
- ♿ Accesible

## 🛠️ Tecnologías

- React 18
- Next.js 14
- TypeScript
- Tailwind CSS
- Framer Motion

## 🚀 Inicio

npm install
npm run dev
